# Basic Computer Emulator
In this project, I take what I've learned from some of my computer engineering/organization classes and created a program in C++ that seeks to emulate the way programmers used to input bits one-by-one (a.k.a., machine code) in order to code programs. Still a work-in-progress.

This project was previously an attempt to implement my own machine code coding language but now it has turned into a project on emulating a computer. 

Just type
```
make
./Computer_EMU 
```
to run.
